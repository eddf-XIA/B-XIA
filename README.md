### DailyScope: AI-powered continuous research for Android

[**eddf-XIA/DailyScope**](https://github.com/eddf-XIA/DailyScope)

DailyScope turns evolving topics into persistent research streams. It runs web-grounded AI research, validates the structured result, tracks events across runs, and produces source-backed reports that separate what is new from what has changed.

- **Android:** Kotlin, Jetpack Compose, Room, DataStore, OkHttp, JobScheduler, Android Keystore (AES-GCM); English and Simplified Chinese with per-app language switching.
- **AI pipeline:** structured output with schema validation, deterministic recovery and at most one bounded repair, stable event identity across runs, and exactly one paid call per run by construction.
- **Backend foundation:** Kotlin/Ktor, PostgreSQL, Flyway, JWT access tokens with rotating refresh tokens, and concurrency tests against a real database. Implemented, not yet deployed.
- **Testing:** about 1,700 automated JVM tests, golden fixtures for behavioral parity with an earlier Python version, screenshot tests, and validation on a physical Android 16 device.

The repository is an engineering portfolio (documentation, diagrams, screenshots); the source code is private.

### Honey bee pollen research

Research on the pollen that honey bees collect, combining image analysis with molecular data:

- image processing of pollen samples in Python with OpenCV;
- colour analysis in the CIELAB colour space;
- integrating image-derived measurements with DNA metabarcoding results;
- statistical modelling of ecological research data.

This work is not public.
